# Magic 8-Ball (Магический шар) 🎱

Консольная мини-игра на Python, которая предсказывает будущее и отвечает на любые вопросы в стиле классического «Магического шара 8».

## Как запустить

1. Убедитесь, что у вас установлен Python 3.
2. Скачайте файл `magic_8_ball.py`.
3. Запустите скрипт в терминале:
   ```bash
   python3 magic_8_ball.py
   ```
